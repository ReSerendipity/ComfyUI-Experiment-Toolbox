# 04 结果分析

**解决什么问题**：把跑出来的一堆图变成**可比较的数字**和**一眼能看的拼版**，避免"只凭印象说好坏"。

| 文件 | 功能 | 使用方式 | 适用场景 | 依赖 |
|---|---|---|---|---|
| **`analyze_models.py`** ★ | 跨模型分析：逐组算客观指标，并计算**与同模型基线**的相似度与相对变化（锐度/对比度 %），最后生成带标签拼版 | `python analyze_models.py` | 多模型 × 多组合的结果汇总 | numpy + Pillow；读 `OUT` 目录 |
| `metrics.py` | 单模型分析：亮度 / 对比度σ / 锐度(Laplacian 方差) / 色彩度 + 4 列拼版 | `python metrics.py` | 单模型组合矩阵汇总 | 同上 |
| `focus_sheet.py` | **聚焦对照**：挑 3~4 个关键结果做**大图并排**，并输出组合间相似度矩阵（证明"哪些组合实际等价"） | `python focus_sheet.py` | 写报告时做头图；或想量化"两个结果到底像不像" | 同上 |

## 要改的常量
- 三个脚本顶部的 `BASE`（结果根目录）与 `OUT`（图片目录）。

## 指标定义（自己复算时对齐口径）

| 指标 | 算法 | 说明 |
|---|---|---|
| 亮度 | 灰度均值 | 判"发白/发暗" |
| 对比度 σ | 灰度标准差 | **最灵敏的异常探测器**：karras 组普遍从 42 掉到 22 |
| 锐度 | 灰度图 Laplacian 方差（3×3 核滑窗） | 判"糊没糊"。注意：更锐 ≠ 更好看，必须配人眼核对 |
| 色彩度 | Hasler-Süsstrunk：`sqrt(σ_rg²+σ_yb²) + 0.3·sqrt(μ_rg²+μ_yb²)` | 判"发灰/偏色" |
| 相似度 | 灰度缩到 128×128 后 `1 − MSE/255²` | ≈1.0 即肉眼难分；**这是"多组合实际等价"的量化证据** |

## 使用注意
- **指标异常必须回头看图**：指标只能给排序和线索，不能单独下结论。实测中 karras 的缺陷是"双重曝光重影"这类**结构性**问题，指标上只表现为对比度/锐度掉一半。
- 指标是**全图统计量**：主体占画面比例变化会同时影响所有指标，所以只在**同模型同一提示词**下做横向比较才有意义（这正是本包坚持固定提示词与种子的原因）。
- 拼版图按 4 列排布，文件名取前 34 字符做标签；组合名太长会截断，命名时把关键信息放前面。
- 若同一组合重跑过多次，`analyze_models.py` 会**按 (模型, 组合) 去重**只取第一张，避免重复计数。
