### 本机实测过的采样器（Qwen-Image 2.1 / 25 步 / cfg=1 / 1024² / euler+simple 为基线）

| 采样器 | 实测结论 | 与基线相似度 |
|---|---|---|
| `euler` | ✅ 基线，干净锐利 | 1.0 |
| `res_multistep` | ✅ **画质最优族**：`+beta` 锐度 228.1（基线 151.3，**+51%**）、`+simple` 194.8（+29%） | 0.9935 / 0.9979 |
| `euler_cfg_pp` | ✅ 干净，色彩度全场最高；**cfg=1 下仍会消费负向条件**（CFG++ 数学需要 uncond 的 x0），所以结果与 `euler` 不同 | 0.9882 |
| `euler_ancestral` | ⚠️ **相同种子下换构图换姿态**，不可用于复刻场景 | 0.962 |
| `er_sde` | ⚠️ 同上，换构图且偏灰绿（色彩度 38.5 为全场最低档） | 0.949 |
| `dpmpp_2m` / `dpmpp_2m_sde_gpu` / `dpmpp_3m_sde_gpu` / `dpmpp_2s_ancestral` / `heun` / `uni_pc_bh2` | ❓ **未独立验证**：这 6 个只测过 `+karras` 组合，而 karras 本身会把画面毁掉（重影），采样器差异被掩盖，**不能据此判断采样器优劣** | — |
| 其余（heunpp2 / dpmpp_sde / lms / ipndm / deis / lcm / ddpm / sa_solver / seeds_* / gradient_estimation / ddim …） | ❓ **未测** | — |

> **一条已证伪的通用说法**：本文件多处使用"某采样器在低步数达到另一采样器高步数效果""对几乎所有调度器有提升"这类表述——**至少在 Qwen-Image 2.1 上不成立**：本次实测中**调度器的影响远大于采样器**（7 组不同采样器 + karras 全部同样翻车，两两相似度 0.9991~0.9998）。
>
> **选采样器的正确顺序**：先按《调度器名称.md》的结论把调度器定在安全白名单内，再在 `euler` 与 `res_multistep` 之间选采样器。

## 一、Euler 系列（基础一阶采样器，入门首选）

### `euler`
- **原理**：基于一阶前向欧拉法的确定性 ODE 求解器，扩散模型最基础的采样算法，每步仅 1 次模型评估，无额外随机项。
- **核心特点**：速度极快、开销最低；相同种子/参数结果 100% 复现；画面干净锐利。
- **适用场景**：快速预览、批量生成、新手入门，适配 20–30 步常规生成。
- **缺点**：低步数细节一般，高步数易生硬、噪点。

### `euler_cfg_pp`
- **原理**：Euler 基础上集成 CFG++ 引导优化，修正传统 CFG 的过拟合与提示词偏离。
- **核心特点**：保留 Euler 速度，提示词遵循度与细节控制更强，缓解高 CFG 过曝/伪影；确定性可复现。
- **适用场景**：需要精准还原提示词、高 CFG 场景。
- **🔑 与 cfg 的特殊关系（2026-09-23 源码核实）**：**普通采样器在 cfg=1 时会跳过无条件分支、完全不用负向提示词**（`comfy/samplers.py` `sampling_function` 里 `uncond_ = None`）；但 **`*_cfg_pp` 全族在源码里强制 `disable_cfg1_optimization=True`，cfg=1 下依然计算并使用无条件分支**——CFG++ 的数学需要单独拿到 uncond 的 x0 估计（`sample_euler_ancestral_cfg_pp` 里 `uncond_denoised`）。所以：① cfg_pp 在 cfg=1 下与同族普通采样器**结果并不相同**（实测 `euler_cfg_pp + simple` 与基线 `euler + simple` 相似度仅 0.9882，其余同调度组合 ≥0.9976）；② 想发挥 CFG++ 完整效果仍需提高 cfg 并填写实际负向提示词。涉及 `euler_cfg_pp` / `euler_ancestral_cfg_pp` / `dpmpp_2m_cfg_pp` / `dpmpp_2s_ancestral_cfg_pp` / `res_multistep_cfg_pp` / `res_multistep_ancestral_cfg_pp` / `gradient_estimation_cfg_pp`。详见《采样器和调度器的组合推荐.md》6.6 节。

### `euler_ancestral`（Euler a）
- **原理**：一阶祖先采样器，每步去噪后额外注入随机噪声，属 SDE 类。
- **核心特点**：画面创意和纹理丰富、色彩柔和；相同种子下不同步数/调度器结果完全不同，不可复现。
- **适用场景**：艺术创作、创意发散、二次元/插画；不适合精准复刻。
- **缺点**：稳定性差，调步数画面大变，难控元素。

### `euler_ancestral_cfg_pp`
- **原理**：Euler a 与 CFG++ 结合，在随机性基础上优化提示词遵循与控制。
- **核心特点**：保留创意性，同时改善 Euler a 提示词贴合弱、元素易失控。
- **适用场景**：既要随机艺术感、又要核心元素可控的创意生成。

## 二、Heun 系列（二阶精度，Euler 进阶）

### `heun`
- **原理**：二阶 Heun 法（改进欧拉/梯形法），每步先欧拉预测再中点校正，单步 2 次模型评估。
- **核心特点**：过渡平滑、噪点少、细节柔和；确定性可复现；复杂光影纹理表现好。
- **适用场景**：写实、人像，20–40 步中高质量。
- **缺点**：速度约 Euler 的一半，低步数易模糊。

### `heunpp2`
- **原理**：Heun 的第二版伪概率优化（Pseudo-Probability v2），优化数值积分的伪概率拟合。
- **核心特点**：比 heun 精度更高、细节更丰富、噪点控制更好；材质/毛发/纹理更强。
- **适用场景**：超高精度写实、工业渲染、复杂纹理，30 步以上。

### `exp_heun_2_x0`
- **原理**：SEEDS 采样框架下的 `phi_2` 求解器配置（r=1.0, eta=0），属指数型随机求解器家族，并非传统 Heun 变体。
- **核心特点**：与 SEEDS 框架配套，日常较少用。
- **适用场景**：SEEDS 框架实验性使用。

### `exp_heun_2_x0_sde`
- **原理**：`exp_heun_2_x0` 的 SDE 随机版本（eta=1.0, s_noise=1.0），在 phi_2 框架下引入噪声项。
- **核心特点**：保留快速收敛与结构精度，SDE 随机性带来纹理/光影自然度。
- **适用场景**：兼顾结构精度与艺术氛围，如写实人像、风景。

## 三、DPM 基础系列（扩散模型初代求解器）

### `dpm_2`
- **原理**：DPM-Solver-2 二阶求解器，二阶 Taylor 展开近似噪声预测。
- **核心特点**：确定性，20 步达传统 40 步效果；提示词利用率高、细节贴合好。
- **适用场景**：中低步数高质量、精准还原提示词。
- **缺点**：每步 2 次评估，慢于 Euler。

### `dpm_2_ancestral`（DPM2 a）
- **原理**：DPM2 的祖先版本，每步注入随机噪声。
- **核心特点**：保留 DPM2 提示词利用率，同时更灵动、色彩过渡自然；不可复现。
- **适用场景**：创意插画、艺术风格。

### `dpm_fast`
- **原理**：一阶 DPM 极速版，均匀噪声调度，每步 1 次评估。
- **核心特点**：速度近 Euler，保留 DPM 基础适配。
- **适用场景**：极速预览、批量低精度。
- **缺点**：细节弱于二阶 DPM，易伪影/结构崩。

### `dpm_adaptive`
- **原理**：自适应步长一阶 DPM，按噪声水平自动调整步长，无视固定步数。
- **核心特点**：收敛稳定、细节还原好、几乎不崩。
- **适用场景**：复杂高难度画面。
- **缺点**：速度不可控，DPM 系列中最慢。

## 四、DPM++ 系列（当前主流首选）

### `dpmpp_2s_ancestral`（DPM++ 2S a）
- **原理**：DPM-Solver++(2S) 二阶单步祖先采样，单步二阶 + 每步随机注入。
- **核心特点**：15–25 步出高质量；创意强、纹理丰富，二次元/插画适配好。
- **适用场景**：二次元、创意艺术、中低步数快速出图。
- **缺点**：不可收敛，调步数画面大变。

### `dpmpp_2s_ancestral_cfg_pp`
- **原理**：2S a + CFG++，优化高 CFG 引导。
- **核心特点**：保留快速收敛与创意，改善高 CFG 伪影/元素失控。
- **适用场景**：复杂提示词的创意生成。

### `dpmpp_sde`
- **原理**：DPM-Solver++ 单步 SDE，布朗运动噪声模型，可控随机性。
- **核心特点**：纹理真实、光影柔和；相比祖先采样主体一致性更高。
- **适用场景**：写实、人像、风景。

### `dpmpp_sde_gpu`
- **原理**：`dpmpp_sde` 的 GPU 优化版，噪声生成与张量计算全绑 GPU。
- **核心特点**：效果同原生，速度更快、显存更优，适合高分辨率。
- **适用场景**：GPU 高分辨率、批量生成。

### `dpmpp_2m`
- **原理**：DPM-Solver++(2M) 二阶多步确定性求解，复用历史步预测校正，单步单次评估实现二阶精度。
- **核心特点**：20–30 步达顶级画质；确定性可复现；细节足、提示词遵循强、稳定性极高。
- **适用场景**：通用型首选，全风格全步数。

### `dpmpp_2m_cfg_pp`
- **原理**：2M + CFG++，优化 CFG 逻辑，解决过饱和/伪影。
- **核心特点**：高 CFG 下更稳，提示词遵循更强，细节色彩更准。
- **适用场景**：高 CFG 精准生成、商业级高质量。

### `dpmpp_2m_sde`
- **原理**：2M 的 SDE 扩展，二阶多步确定性 + 随机微分方程。
- **核心特点**：真实感拉满，材质/光影/毛发自然；主体一致性高，仅纹理随机。
- **适用场景**：超写实人像、摄影级风景、产品渲染。

### `dpmpp_2m_sde_gpu`
- **原理**：`dpmpp_2m_sde` 的 GPU 版。
- **核心特点**：效果同原生，速度/显存更优，适合 4K+ 高分辨率。
- **适用场景**：GPU 高分辨率写实、批量商业出图。

### `dpmpp_2m_sde_heun`
- **原理**：在 2m_sde 上集成 Heun 二阶梯形校正，降低离散误差。
- **核心特点**：噪点更少、光影更平滑、暗部/柔材质更优。
- **适用场景**：弱光、人像特写、柔焦风格。

### `dpmpp_2m_sde_heun_gpu`
- **原理**：`dpmpp_2m_sde_heun` 的 GPU 版。
- **适用场景**：GPU 高分辨率人像、柔焦、弱光高质量生成。

### `dpmpp_3m_sde`
- **原理**：DPM-Solver++(3M) 三阶多步 SDE，三阶精度，复用更多历史步。
- **核心特点**：收敛精度更高，低步数即极致细节；复杂场景/微小细节/材质远超二阶。
- **适用场景**：超高精度写实、复杂大场景、工业级，20 步以上。
- **缺点**：开销略高，<15 步优势不明显。

### `dpmpp_3m_sde_gpu`
- **原理**：`dpmpp_3m_sde` 的 GPU 版。
- **适用场景**：GPU 超高精度、高分辨率复杂场景、影视级渲染。

## 五、经典扩散采样系列

### `ddpm`
- **原理**：Denoising Diffusion Probabilistic Models，马尔可夫链反向扩散，每步预测噪声并逐步移除。
- **核心特点**：完全随机、多样性强、纹理丰富；理论收敛最优。
- **适用场景**：学术研究、基础模型验证。
- **缺点**：需数百步，日常效率极低。

### `ddim`
- **原理**：Denoising Diffusion Implicit Models，非马尔可夫采样，支持跳跃去噪。
  > 注意：ComfyUI 内置的 `ddim` 实际由 euler 采样器加随机项实现（非论文原版 DDIM），日常可视为带随机性的 euler。
- **核心特点**：确定性可复现；比 DDPM 快，20–50 步可用；支持隐空间插值，连贯性强。
- **适用场景**：图生图重绘、修复、GIF/视频帧插值。
- **缺点**：低步数易模糊/伪影，创意还原弱于祖先采样。

### `lcm`
- **原理**：Latent Consistency Model，潜在一致性模型专属，专为一致性蒸馏设计。
- **核心特点**：4–8 步出极高质量，当前最快高质量采样；确定性可复现。
- **适用场景**：LCM 模型专属，极速实时/批量/直播。
- **注意**：仅适配 LCM 蒸馏模型，原生 SD 模型上表现差。

## 六、多步线性 / 高阶系列

### `lms`
- **原理**：Linear Multistep，线性多步求解，复用前序多步梯度信息线性拟合，每步 1 次评估。
- **核心特点**：收敛快于 Euler、近二阶；稳定可复现；风格中性。
- **适用场景**：常规文生图，替代 Euler 更快收敛。
- **缺点**：对调度器极敏感，适配不当易崩；高步数提升有限。

### `ipndm`
- **原理**：Improved PNDM，四阶改进型伪线性多步，基于 Adams-Bashforth 方法。
- **核心特点**：四阶精度、低步数高保真、数值稳定。
- **适用场景**：低步数快速高质量，建筑/机械等结构精准场景。

### `ipndm_v`
- **原理**：`ipndm` 的可变步长版本，优化非均匀调度下的拟合。
- **核心特点**：对非均匀调度（如 Karras）适配更强。
- **适用场景**：通用型高精度，配 Karras 的中低步数出图。

### `deis`
- **原理**：Diffusion Exponential Integrator Sampler，半线性 ODE 指数积分器。
- **核心特点**：高阶精度、10 步即高保真、数值稳定几乎不崩。
- **适用场景**：极速高质量、低步数预览。

### `cfgpp_ud10_ab`
- **原理**：CFG++ 引导与 Ud10 蒸馏/速度优化变体结合的实验性采样器，面向低步数蒸馏模型。
- **核心特点**：较新的实验组合，官方文档少。
- **适用场景**：实验尝鲜、特定蒸馏模型；日常用 euler+beta 或 res_multistep 即可。

## 七、重启 / 小众 / 前沿采样器

### `res_multistep`
- **原理**：Restart Multistep，重启式多步采样器（**res 是 restart 重启，不是 residual 残差**）。在去噪中周期性注入噪声并重新开始，通过阶段性重启改善求解轨迹。
- **核心特点**：与 Qwen-Image、Z-Image 等新一代蒸馏模型高度匹配，低步数稳定出图；确定性可复现。
- **适用场景**：Z-Image-Turbo、Qwen-Image 蒸馏版等官方默认采样，4–15 步快速稳定。

### `res_multistep_cfg_pp`
- **原理**：`res_multistep` 的 CFG++ 优化版，优化引导逻辑。
- **核心特点**：保留重启多步精度稳定性，提升提示词贴合，缓解高 CFG 伪影/过饱和。
- **适用场景**：复杂提示词长步数高精度、高 CFG 精准出图。

### `res_multistep_ancestral`
- **原理**：`res_multistep` 的祖先版本，重启框架上每步注入随机噪声。
- **核心特点**：兼顾重启多步的高精度结构稳定与祖先采样的创意纹理；主体一致性更高。
- **适用场景**：结构精度与创意兼顾的艺术生成。

### `res_multistep_ancestral_cfg_pp`
- **原理**：`res_multistep_ancestral` + CFG++。
- **适用场景**：多元素提示词，既要艺术随机性又要核心元素精准。

### `gradient_estimation`
- **原理**：基于梯度估计的高阶采样器，每步通过模型反向传播额外估计梯度方向；仍依赖模型前向预测（**不是无模型**），但计算量显著更大。官方定位极端场景小众。
- **核心特点**：精度上限高，但速度极慢（普通采样器数倍耗时）。
- **适用场景**：普通采样器出问题时才试；学术研究。

### `gradient_estimation_cfg_pp`
- **原理**：`gradient_estimation` 的 CFG++ 版，叠加引导逻辑，速度更慢。
- **适用场景**：小众模型的高 CFG 推理。

### `er_sde`
- **原理**：Extended Reverse-Time SDE，扩展反向时间随机微分方程求解器。
- **核心特点**：20 次以内函数评估即可达高 FID；保留 SDE 多样性与自然感。
- **适用场景**：学术研究、高效率+高质量兼顾。

### `seeds_2`
- **原理**：SEEDS（Stochastic Exponential Expansion）系列二阶求解器。ComfyUI 官方未公开详细文档，定位实验/内部。
- **核心特点**：实验性，日常不推荐；`exp_heun_2_x0` 是其一个配置。
- **适用场景**：实验尝鲜，不建议生产。

### `seeds_3`
- **原理**：SEEDS 系列三阶求解器，官方未公开，实验性。
- **核心特点**：比二阶收敛更快、低步数精度更高。
- **适用场景**：低步数超高精度实验。

### `sa_solver`
- **原理**：Stochastic Adams Solver，随机亚当斯多步 SDE 求解器（NeurIPS 2023）。
- **核心特点**：多步 SDE 效率高，模型评估次数少；质量与多样性平衡，FID SOTA。
- **适用场景**：前沿高质量、学术研究。

### `sa_solver_pece`
- **原理**：`sa_solver` 的 Predict-Evaluate-Correct-Evaluate 预测-校正版。
- **核心特点**：精度更高、离散误差更低、收敛更强。
- **适用场景**：超高精度 SDE 采样、工业级生成。

### `uni_pc`
- **原理**：Unified Predictor-Corrector，统一预测-校正框架，无训练快速采样。
- **核心特点**：10–20 步顶级画质；模型无关；确定性可复现。
- **适用场景**：通用快速高质量、SDXL/高分辨率，低步数首选之一。

### `uni_pc_bh2`
- **原理**：`uni_pc` 的二阶 B(h2) 优化版，低步数阶数匹配。
- **核心特点**：低步数收敛更快、开销更低，保留高阶精度。
- **适用场景**：中低步数常规出图、批量生成。
