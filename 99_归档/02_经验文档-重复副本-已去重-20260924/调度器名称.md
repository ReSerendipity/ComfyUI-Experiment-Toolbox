# ComfyUI 调度器名称速查

> 基于本机 `comfy/samplers.py` 的 `SCHEDULER_NAMES` 共 **9 个调度器**。
> 调度器定义采样全过程噪声水平（sigma）的变化曲线，决定每一步噪声幅度，直接影响收敛效率、细节与风格。

---

| 标记 | 含义 |

> **为什么是这 3 个 `use_ms=False` 的调度器出问题**：`use_ms=True` 的调度器 σ 取值直接来自**模型自身的 training σ 表**；`use_ms=False` 的只用 σ 的两个端点套通用公式（karras 来自 EDM 论文 rho=7），在 flow 模型（σ∈[0,1]）上曲线形状会完全变味。
>
> **一句话结论**：flow 系模型（Qwen / Krea2 / FLUX / FLUX.2 / Z-Image）**统一避开 `karras` 与 `exponential`**；步数 ≤8 的蒸馏模型再额外避开 `kl_optimal`。
>
> ✅ **上表已于 2026-09-23 用统一提示词/种子的跨模型实拍验证**（5 个模型 17 组，`karras` 劣化 25%~97%、`exponential` 更甚、`kl_optimal` 在 8 步模型上 −33%~−44% 锐度/对比度），详见《采样器和调度器的组合推荐.md》第九节。

### `simple`
- **原理**：最基础的简单线性调度，sigma 从最大到 0 全程线性均匀递减，扩散模型最原生的调度。
- **核心特点**：逻辑简单、步长均匀、可预测性强；高步数下画面锐利干净、收敛稳定。
- **适用场景**：基础测试、确定性采样器常规生成，适配 Euler、Heun 等一阶/二阶采样器；也是 Z-Image-Turbo、FLUX 蒸馏模型的官方默认配套。
- **缺点**：低步数收敛弱，易模糊/细节缺失，不适合 20 步以内快速生成。

### `sgm_uniform`
- **原理**：SGM（Score-Based Generative Modeling）论文提出的均匀时间步调度，源码实现为 `normal_scheduler(sgm=True)`，在时间步空间均匀分布；主要服务 SD3 / MM-DiT 等新一代 DiT 模型，并非 SD1.x 时代默认。
- **核心特点**：与新一代 DiT 模型训练目标匹配；步长均匀、采样稳定、兼容性好。
- **适用场景**：SD3 / MM-DiT / Qwen 系等新模型的通用文生图。
- **缺点**：低步数收敛弱于 Karras。

### `karras`
- **原理**：Karras 等人论文提出的非线性噪声调度，高噪声区大步长、低噪声区小步长。
- **核心特点**：综合表现最优，约 20 步达其他调度 40 步效果；细节/对比度/纹理极强，对几乎所有采样器有画质提升。
- **适用场景**：通用型首选，全采样器/全模型/全步数。
- **缺点**：高步数下略慢于线性，差异极小。
- **⚠️ 例外（2026-09-22/23 实测＋离线验证）**：**Qwen-Image 2.1（int8_convrot，25 步 / cfg=1 / 1024²）上 karras 会严重翻车**——7 组不同采样器全部出现双重曝光鬼影＋发白雾化，对比度 σ 由 42 塌至 22、锐度 −64%，且与采样器无关。
  **根因（离线算 σ 曲线验证，非推断）**：本模型是 flow matching，**时间轴 = σ，σ∈[0.00069, 1.0]**；而 karras 曲线（EDM 论文，rho=7）只有 σ 的两个端点、是为 DDPM 那种 σ_max≈14.6 的大动态范围设计的。套到本模型上就把步数错堆到低噪声区：**σ>0.5（定大结构的阶段）只分到 4/25 步，首步一次跨 Δσ=0.174（`simple` 只有 0.057，3.1 倍）**，一阶求解器误差被放大 → 全局结构跑偏成重影；后段 14 步虽多，只是在错轨迹上精修。50 步时首步 Δσ 减半至 0.089，重影随之基本消失。
  详见《采样器和调度器的组合推荐.md》第七节。

### `exponential`
- **原理**：指数型噪声调度，sigma 以指数函数递减，初期降得极快、后期大幅放缓。
- **核心特点**：低步数收敛快，快速搭建主体结构。
- **适用场景**：10 步内极速预览、LCM 等极速采样器配套。
- **缺点**：高步数易过曝/细节丢失，不适合 20 步以上精细生成。
- **⛔ 高危（2026-09-23 离线验证）**：本机 Qwen-Image 2.1 上，`exponential` 是**全部 9 个调度器里最激进的一条曲线**——25 步时 σ>0.5 只分到 **3 步**、首步 Δσ = **0.262**（karras 是 4 步 / 0.174）。按第七节判据（首步 Δσ > 0.15σ_max 基本判死）**预计比 karras 更糟，本模型请直接避开**。该项**尚未实拍验证**（用户已要求暂停跑图），待补测。

### `ddim_uniform`
- **原理**：专为 DDIM 采样设计的均匀调度，基于 DDIM 非马尔可夫特性优化均匀步长。
- **核心特点**：与 DDIM 适配强，插值连贯性/重绘稳定性提升；确定性可复现。
- **适用场景**：DDIM 采样专属，图生图重绘、修复、帧插值、GIF/视频。
- **注意**：非 DDIM 采样器上表现远弱于 sgm_uniform 与 Karras。

### `beta`
- **原理**：基于 beta 分布的噪声调度（ComfyUI 实现见 arXiv:2407.12173），曲线遵循 beta 分布，可调成凸或凹。**Qwen-Image 官方教程推荐使用 beta**。
- **核心特点**：曲线灵活适配不同步数/模型；过渡平滑、噪点控制好。
- **适用场景**：Qwen-Image 系全量模型、柔和风格、人像特写、需要平滑噪声过渡的场景。
- **✅ 实测（2026-09-22）**：在本机 Qwen-Image 2.1 上，`beta` 与 `simple` / `sgm_uniform` / `normal` **实际等价**（相似度 ≥0.9976，肉眼无法区分）；真正拉开画质差距的是**采样器**——`res_multistep + beta` 锐度比官方基线 `euler + simple` 高 51%。详见《采样器和调度器的组合推荐.md》第六节。

### `normal`
- **原理**：标准线性调度（normal linear），sigma 从最大到 0 按均匀线性比例递减。名称中的 normal 意为"普通/标准"，**与正态（高斯）分布无关**；与 karras 非线性曲线对应，是最朴素的 sigma 分布。
- **核心特点**：稳定、主体结构搭建快、后期细节充分；风格中性、兼容性均衡。
- **适用场景**：常规文生图通用场景、基础测试。
- **缺点**：收敛/细节弱于 Karras，无突出专项。

### `linear_quadratic`
- **原理**：线性-二次混合调度，前半段线性降（快速定结构）、后半段二次曲线降（磨细节）。
- **核心特点**：兼顾线性快速收敛与二次精细优化，前期成型快、后期细节好。
- **适用场景**：中高步数精细生成、复杂大场景、写实风格。
- **缺点**：低步数一般，不适合 20 步以内。

### `kl_optimal`
- **原理**：基于 KL 散度最优理论，最小化采样分布偏差，使每步噪声分布与模型训练分布高度匹配。
- **核心特点**：与训练分布契合度极高，画面还原/提示词遵循极强，伪影崩坏风险低。
- **适用场景**：高质量高保真、自定义训练模型推理、商业/工业级精准生成。
