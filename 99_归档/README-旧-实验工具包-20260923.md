# ComfyUI 采样器 / 调度器受控对比 · 复用工具包

> 来源：2026-09-22 ~ 09-23 的「ComfyUI flow 模型 采样器 × 调度器 受控对比实验」任务沉淀。
> 目的：把当时写的一次性脚本整理成**可直接复用的工具 + 方法**，下次换模型/换工作流时不用从零再写。
> 本包是**快照**：其中的参考文档原件仍在 `ComfyUI\user\default\workflows\`，结论若有更新以原件为准。
>
> ✅ **建包时已实测校验**：① 按第四节的 `PYTHONPATH` 方案，`flatten` / `build_prompt` / `run_models` 跨目录 import 全部成立；② `02_调度器sigma分析/sigma_matrix.py` 在新位置可独立运行并输出完整风险矩阵。

```bash

python/python.exe -s ComfyUI/main.py --port 8188 --disable-auto-launch --disable-comfy-compiler
```

## 四、脚本依赖关系（跨目录复制后必须看这条）

脚本之间靠**同目录 import** 互相调用（每个脚本开头有 `sys.path.insert(0, 脚本所在目录)`）。本包按类别分到了 01~04，**直接双击运行会 import 失败**。两种解决方式：

**方式 A（推荐，不改脚本）**：把包根与相关子目录都加进 `PYTHONPATH`，再运行。

```bash
ROOT="%USERPROFILE%/Desktop/ComfyUI-采样器调度器实验工具包"
export PYTHONPATH="$ROOT/01_工作流扁平化;$ROOT/03_受控跑测;$ROOT/04_结果分析"
"$PY" "$ROOT/03_受控跑测/run_models.py"
```

> Windows 下 `PYTHONPATH` 的分隔符是分号 `;`。用 Git Bash 时写 `;` 即可（脚本内 `sys.path` 会用原样字符串）。

**方式 B（最省事）**：把 `01~04` 里你要用的脚本**临时拷到同一个目录**再跑。

依赖矩阵：

| 脚本 | 依赖 |
|---|---|
| `flatten.py` | 无（只依赖标准库） |
| `sigma_report.py` / `sigma_matrix.py` | 需要能 `import comfy.*` → 用 ComfyUI 的 python |
| `run_combos.py` | `build_prompt` |
| `probe.py` / `cfg_probe.py` | `build_prompt`、`run_combos` |
| `run_models.py` | `flatten` |
| `metrics.py` / `focus_sheet.py` / `analyze_models.py` | 无（numpy + Pillow），只依赖输出目录 |

## 六、快速上手（4 步）

```bash
PY="%USERPROFILE%/APP/ComfyUI-aki-v3/python/python.exe"
P="%USERPROFILE%/Desktop/ComfyUI-采样器调度器实验工具包"

# ① 先离线筛调度器：不用跑图，直接得到「该模型该避开哪些调度器」
```

## 七、适用与不适用

**适用**
- flow matching 类模型（Qwen-Image 系、Krea2、FLUX 系、Z-Image 系）的采样器 / 调度器 / steps / cfg 对比
- 任意「新版 `definitions.subgraphs` 子图格式」工作流的 headless 跑图
- 需要固定提示词与种子的对照实验设计

**不适用 / 需另做**
- **Non-KSampler 采样链路**（如 MiniMax H3 视频走 Spectrum 自定义链路）：扁平化能跑，但「换调度器」这个维度不存在
- 图生图 / 编辑类工作流：需要参考图，提示词维度不通用
- 分辨率、LoRA 等其它维度：框架通用，但 `PLAN` 表与覆盖参数要自己改

## 八、先记住这几条结论，能省很多时间

1. **调度器的适配性由「模型自身的 σ 曲线」决定，换模型等于重新洗牌** —— 别照搬别的模型上好用的调度器。
2. **flow 系模型统一避开 `karras` 与 `exponential`**（7/7 模型高危）；步数 ≤8 的蒸馏模型再避开 `kl_optimal`。
3. **安全白名单**：`simple` / `beta` / `sgm_uniform` / `normal` / `ddim_uniform` / `linear_quadratic`。
4. **换调度器的影响远大于换采样器**（7 组不同采样器 + karras 全部同样翻车，两两相似度 0.999~1.000）。
5. **判断一个调度器能不能用，先离线算，不用跑图**：看「高噪声区（σ>0.5σ_max）分到几步」与「首步 Δσ 占 σ_max 百分之几」——首步 Δσ > 15% 基本判死。
6. **cfg=1 时负向提示词完全不被使用**（源码里无条件分支被置空）；唯一例外是 `*_cfg_pp` 全族。所以「没有负向提示词」不是提高 cfg 的理由。
7. **子图容器的 `widgets_values`（positional）才是运行时真值**（前端设置 `Comfy.Workflow.NamedValuesRestore` 默认 false）；读参数值要读它，别读子图内部节点的旧值。
