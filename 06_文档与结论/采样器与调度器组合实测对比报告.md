## 三、画面效果差异总结（三类）

### A 类｜干净可用族（01 / 02 / 03 / 05 / 06 / 14 / 17 / P2）
两张东亚女性依偎在黄昏露台/咖啡馆、背景可见吊桥与晚霞——**与提示词"场景吊桥、亭台观雨、夜幕降临的金黄光线"高度吻合**。面部结构正常、发丝与针织衫纹理清晰。

- **01 / 02 / 03 / P2 几乎完全一致**：两两相似度 0.9976 ~ 1.0000（128px 灰度归一化互似度），肉眼难以区分。说明在本模型上 `simple` / `beta` / `sgm_uniform` / `normal` 四种线性或近线性调度**实际效果等价**。
- **05 / 06（res_multistep）明显更锐**：锐度 194.8 / 228.1，相对基线（151.3）提升 29% / 51%；06 的针织衫编织纹理、发丝分层最清楚，是本批**画质最优**。
- **17（linear_quadratic）** 观感与基线接近，细节略柔和。
- **14（euler_cfg_pp）** 对比度与色彩度全场最高（50.38 / 57.43），画面更"浓"，但因 cfg=1（无负向提示词），CFG++ 的引导修正几乎无处施力，观感差异主要来自随机路径而非引导本身。

### B 类｜karras 异常族（04 / 07 / 08 / 09 / 10 / 12 / 13）——**本次最重要的发现**
7 组不同采样器 + karras 全部出现**同一类严重缺陷**：画面呈"双重曝光 / 鬼影叠影"，人脸五官被打散模糊，整体发白、雾化、对比度塌陷（σ 仅 21~23，约为基线的一半），背景也换成与基线完全不同的店内饰物场景。

- 客观指标一致恶化：亮度 +14%、对比度 −49%、锐度 −64%、色彩度 −17%。
- **与采样器无关**：7 组里既有确定性（dpmpp_2m、heun、uni_pc_bh2）也有随机型（dpmpp_2s_ancestral、dpmpp_2m_sde_gpu），表现却高度雷同——两两相似度 **0.9991 ~ 0.9998**，几乎逐像素级一致（07 vs 12 = 0.9998）。
- **与基线差异极大**：01 vs 04 相似度仅 0.9775，是本批所有非 karras 配对中最低的一档。

**结论：在这套 Qwen-Image 2.1 + 25 步 + cfg=1 的配置下，karras 是关键破坏因素，采样器选谁都不重要（sampler 差异被 scheduler 完全掩盖）。**

#### 补充验证（证据链）
| 验证 | 结果 | 说明 |
|---|---|---|
| P1：euler + karras，**steps 25 → 50** | 重影基本消失，人脸恢复清晰，仅残留一层轻雾 | 说明 karras 的失败模式是**低噪声区步数不足 / 去噪未走完**，而非调度器完全不可用 |
| P2：euler + normal，steps=25 | 干净，与基线相似度 0.9976 | 说明"非线性调度"本身不是问题，`normal` 这种标准线性调度表现与 `simple` 一致 |

> 机制推断（基于实测现象，非文献结论）：karras 曲线把步长集中在高噪声区、低噪声区步长极小，25 步时低噪声区实际可用步数过少，模型在本该"磨细节"的最后阶段没有足够迭代，于是留下未收敛的叠影。把步数翻倍后（P1）低噪声区步数补足，重影随之消失。**未做精确 sigma 曲线数值验证，故此条标注为推断。**

### C 类｜换构图族（11 / 15）
- **11（euler_ancestral + simple）**：画面干净锐利，但**场景完全换了**——变成室内暖光咖啡馆、无吊桥背景，人物姿态也不同。色彩度 36.34 为全场最低（色调更收敛、更"闷"）。与基线相似度仅 0.962。
- **15（er_sde + simple）**：同样换为室内场景，锐度 180.9 偏高、色彩度 38.50 偏低，整体偏灰绿。

两者都是"随机/半随机"采样器，在**同一种子**下依然走向了另一条去噪轨迹——符合文档中"祖先类采样器不可复现、元素难控"的描述。**这类采样器不适合需要复刻固定构图的场景。**

### D 类｜中间态（16）
**16（euler + kl_optimal）**：构图与基线接近（相似度 0.9899），但对比度只有 29.32（基线 42.18），画面自带一层柔和雾感，介于 A 类与 B 类之间。锐度 114.1 尚可，属于"能用但风格明显不同"。

## 四、结论与推荐

1. **保持官方原值 `euler + simple` 是最稳妥的选择**——干净、快（20s）、可复现，且与 `beta` / `sgm_uniform` / `normal` 效果等价，没必要在它们之间来回换。
2. **想要更高画质纹理，推荐 `res_multistep + beta`（06）**：锐度比基线高 51%，五官与织物纹理最扎实，耗时仅多 2s。次选 `res_multistep + simple`（05）。
3. **本配置下不要用 `karras`**：7 组测试 100% 复现重影缺陷，是本模型（Qwen-Image 2.1，官方指定 `simple`）与 karras sigma 曲线不匹配所致；若确要用，需把步数提到 50 左右才能基本恢复（P1），性价比很低。
4. **需要固定构图时避免 `euler_ancestral` / `er_sde`**：即便种子相同也会换场景、换姿态，调度器怎么配都压不住。
5. **`euler_cfg_pp` 在 cfg=1 下无实际收益**（引导项无从生效），要发挥它必须提高 cfg 并配负向提示词——但那已超出本次"参数不变"的约束。
6. **`*_gpu` 后缀不影响效果**（08/09 与对应非 GPU 版同族表现一致），只影响速度/显存。

**一句话**：换调度器的影响远大于换采样器。本模型请把调度器钉在 `simple` / `beta` 一带，采样器在 `euler` 与 `res_multistep` 之间二选一即可，其余组合要么无差别、要么直接翻车。
