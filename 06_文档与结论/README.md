## 三份结论的「证据等级」约定

文档里对每条结论都标了来源，请按等级取用：

| 标记 | 含义 |
|---|---|
| ✅ **实拍 / 离线计算** | 本机有实际证据（有数据、有图、有脚本可复现） |
| 🟢 **源码可证** | 能直接在 ComfyUI 源码里读到实现 |
| 🟡 **社区经验** | 常见说法，本机无证据，**引用前需自行验证** |

> 原则：**实践是检验真理的唯一标准** —— 没在本机跑过或算过的说法，不写进结论表，只留在"社区经验"档。

## 必记的 7 条

1. 调度器适配性由**模型自身的 σ 曲线**决定，换模型等于重新洗牌。
2. flow 系模型统一避开 **`karras`** 与 **`exponential`**（7/7 模型高危）。
3. 步数 ≤8 的蒸馏模型额外避开 **`kl_optimal`**。
4. 安全白名单：`simple` / `beta` / `sgm_uniform` / `normal` / `ddim_uniform` / `linear_quadratic`。
5. **换调度器的影响远大于换采样器**。
6. **cfg=1 时负向提示词完全不被使用**；唯一例外是 `*_cfg_pp` 全族（CFG++ 的数学需要 uncond）。所以"没有负向提示词"不是提高 cfg 的理由。
7. 子图容器的 `widgets_values`（positional）才是运行时真值（前端设置 `Comfy.Workflow.NamedValuesRestore` 默认 false）。
