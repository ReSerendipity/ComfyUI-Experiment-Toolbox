# MOSS-Image 版式化文生图实测结论

> 记录日期：2026-10-29 ｜ 模型：`moss_image_sft_int8_convrot` ｜ 场景：把一张图当版面生成
>
> 本文只记结论与可复现口径。参考图与复刻样张为他人作品及其派生，留在实验工作区，不入库；
> 原创的 10 类样张见 `11_版式化文生图/samples/`。
>
> 工具与类型库：`11_版式化文生图/`；方法论：`11_版式化文生图/docs/版式化提示词七要素.md`

## 1. 复刻验证

基准取自 ModelScope AIGC 专区两件版式化作品：游戏王怪兽卡（2:3 竖版）与九格漫画分镜页（9:16）。
原作提示词在分享页被折叠，且页面是 SPA、提示词由客户端加载，服务端 HTML 里没有；
用无头浏览器 `--virtual-time-budget` 等 JS 跑完再 dump DOM 才能取到全文
（`/api/v1/aigc/*` 各猜测端点均 404）。

| 项 | 怪兽卡 | 九格漫画页 |
|---|---|---|
| 原作分辨率 | 1200×1800 | 720×1280 |
| 原作参数 | euler / 30 步 / CFG 4 | euler / 30 步 / CFG 4 |
| 复刻分辨率 | 1024×1536（1800 非 16 倍数） | 720×1280（原样） |
| 复刻耗时 | 42.2s | 27.1s |
| 版式命中 | 10/10 | 8/8 |
| 文字命中 | 全部逐字正确（含卡号 `89631143`） | 8 段台词全部可读 |

**结论：可复刻。** 偏差集中在两处：主体细节的自由发挥（龙翼展开角度）、
跨格人物面部一致性（第 5/6 格漂移）。版式与文字层面没有结构性失败。

## 2. 核心结论：版式是先验，文字必须显式注入

同 seed 同参数，把 1751 字结构化提示词换成 9 字短提示「青眼白龙，游戏王卡牌」：

| 项 | 结构化提示词 | 9 字短提示 |
|---|---|---|
| 卡牌结构 | 完整 | **仍然完整** |
| 名称栏文字 | 正确 | 正确（提示词里给了） |
| 说明栏正文 | 逐字一致 | **伪汉字**（笔画像字、不成词） |
| 卡号 | `89631143` | `ISI A00/1602/VP00/6028` |
| 主体配色 | 银白 + 钢蓝 | 被自行染成绿色 |

模型内置「这是一张卡牌」的版式先验，骨架白送；但它不知道要写什么字。
**提示词的长度主要花在逐字规定文字上，不是在描述画面。**

配套的写法约束（详见七要素文档）：

1. 首句锁定「整张…完整展示 / 四边与画面边缘平行 / 居中排列 / 四周留少量 X 背景」
2. 版式骨架按方位词顺序推进，不跳序
3. 每个文字块 `写出：` + 空行 + 原文独占一行 + 排版说明
4. 文字四件套：颜色 + 相对字号 + 字体族 + 对齐
5. 数量与数值写死（8 枚星、9 格、`ATK/3000`）
6. 结尾一段枚举色板做全局收束
7. 否定约束写在相关段落同句内

## 3. 参数消融：不是关键变量

| 口径 | 结果 | 耗时 |
|---|---|---|
| euler / 30 步 / CFG 4（原作标注） | 版式文字全对，锐度略高 | 42.2s |
| er_sde / 25 步 / CFG 2.5（官方模板默认） | 版式文字全对，说明栏文字更连贯 | 39.1s |

**稳定性来自提示词结构，不来自采样参数。** 调优顺序：先改提示词，再动参数。

## 4. 分辨率约束

宽高必须是 **16 的倍数**，总像素 **0.25M–4M**，官方推荐 1M / 1.5M / 2M。
越界不报错但构图会崩；本轨驱动在 `build()` 里直接抛 `ValueError`，不静默降级。

原作 1200×1800 的 1800 不是 16 的倍数，说明 ModelScope 侧对产物做过缩放
（1200/1024 = 1800/1536 = 1.171875，正好是 1024×1536 的等比放大）。

## 5. 静默无图的排查口径

模型名不在 `/object_info` 下拉表时（例如把 `MOSS-Image\xxx.safetensors` 写成裸文件名），
ComfyUI 的行为是：该节点输出被忽略 → 下游剪枝 → 任务 `status=success` 但 `outputs={}`。
**没有任何报错。** 所以本轨的驱动把 `--probe` 作为第一步：
提交前先比对三件套是否在合法值列表里。

## 6. 类型库

两条主线共 10 类，全部单 seed 单次生成通过验收：
A 单画布排版（塔罗牌 / 人物档案卡 / 杂志封面 / 电影海报 / 手机 App 界面 / 产品包装 /
中文信息图 / 建筑立面图）、B 叙事序列（电影故事板 / 四格漫画）。

骨架复用验证：保留怪兽卡全部版式骨架，只换主体、属性、配色与数值，一次生成即全部落位——
**骨架是可复用资产，变体成本只是重写主体段与数值。**

## 7. 边界

| 边界 | 现象 | 处置 |
|---|---|---|
| 文字密度 | 单图 8–12 个文字块可控，超过后小字号块笔画粘连 | 拆页或降低密度 |
| 跨格 / 跨页一致性 | 同页多格脸型漂移；跨页靠逐页复用角色设定卡维持 | T2I 无参考图输入，不追求逐帧一致 |
| 规则几何 | 环形进度弧、条形码条纹被画成近似形 | 接受，或改用非规则表达 |
| 画面元素计数 | 建筑开窗数写 3 出 5 | 文字里的数字可控，画面元素只是概率性服从 |
