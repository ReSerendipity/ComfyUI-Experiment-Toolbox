# 版式化是不是 MOSS-Image 专属？跨模型对照

> 2026-11-02 · 同一段版式化提示词、同一个 seed，两个模型各跑十类版式
> 工具：`11_版式化文生图/model_ab.py`；产物：`11_版式化文生图/samples_ab/`；矩阵页：`11_版式化文生图/ab_matrix.html`

## 结论先说

**不是专属。** MOSS-Image 与 Qwen-Image-2.1-turbo 在全部 **10 类版式**上，
用**完全相同的提示词与 seed**，都拿到了版式落位、文字可读的成品。
Qwen 快约 **2.4 倍**，但质感更平。

差别在**画风**，不在**版式与文字**。

## 为什么只比这两个

先按文字能力筛过一轮。依据是 2026-10-31 的四语文字评测（9 个模型 × 4 种语言，
同提示词同 seed，同一张中文海报：主标 / 副标 / 菜单三行 / 印章 / 页脚）：

| 模型 | 中文表现 | 处置 |
|---|---|---|
| MOSS-Image | 主标 / 副标 / 菜单 / 印章 / 页脚全对 | **入选** |
| Qwen-Image-2.1-turbo | 全对 | **入选** |
| Qwen-Image-2512 | 全对 | 未纳入（本次只保留两个） |
| Z-Image | 全对 | 未纳入 |
| FLUX.3-klein | 1 处错字（炭焙→皮焙） | 未纳入 |
| Z-Image-turbo | 1 处错字（乌龙→鸟龙） | 未纳入 |
| Krea-2-turbo | 菜单多处错字（炭焙→核桃、陈皮→柽皮） | **排除** |
| FLUX.2-klein-9B | 大面积伪汉字（花苑乌龙 / 桃漪孰铡湆） | **排除** |
| FLUX.1-dev | 完全失效，把中文写成韩文 | **排除** |

**版式化任务里，文字写不对等于零。** 所以文字能力不达标的家族不进对照——
它们在版式上或许也能出骨架，但没有比较意义。

## 对照口径

| 项 | MOSS-Image SFT | Qwen-Image-2.1-turbo |
|---|---|---|
| UNET | `moss_image_sft_int8_convrot` | `qwen-image-2.1-turbo-int8-convrot` |
| 文本编码器 | `qwen3.5_9b_int8_convrot`（type=`moss_image`） | `qwen3-vl-8b-heretic-1.3.0_fp8`（type=`qwen_image`） |
| VAE | `flux2-vae` | `qwen_image_2.1_vae_bf16` |
| 潜空间节点 | `EmptyFlux2LatentImage` | `EmptySD3LatentImage` |
| 采样 | euler / 30 步 / CFG 4 / simple | euler / 8 步 / CFG 1.0 / simple + `ModelSamplingAuraFlow` shift 3.1 |
| 负向词 | 同一串（含「文字模糊，文字扭曲，伪汉字」） | 同左 |
| 提示词 | 逐字相同（`layout_types.py`） | 逐字相同 |
| seed | 20261111 | 20261111 |

参数不是调出来的：三件套与采样口径分别按各自官方模板给
（`image_moss_image_t2i.json` / `image_qwen_Image_2512.json`），Qwen 步数按 turbo 口径下调。

## 十类逐类对照

| 类型 | 密度 | MOSS | Qwen | 差异 |
|---|---|---|---|---|
| 塔罗牌 | 标签级 | 结构完整、`XVII`、八星、双水罐、「星辰」全对 | 同左 | MOSS 装饰画风更厚，Qwen 平涂更干净 |
| 人物档案卡 | 标签级 | 代号 / 四项能力条 / 编号 / 等级 / 印章全对 | 同左 | 排版略有差异，均成立 |
| 杂志封面 | 标题级 | 「城市漫游」+ `CITYWALK` + 导读 + 条码全对 | 同左 | MOSS 主视觉更实，Qwen 更亮 |
| 电影海报 | 标题级 | 「静默频率」+ 标语 + credit block 全对 | 同左 | 构图不同，信息齐 |
| 手机 App 界面 | 标签级 | 状态栏 / 数据卡 / 分类 / 列表 / tab 全对 | 同左 | 图标风格不同 |
| 产品包装 | 段落级 | 「山雾山」+ 风味 + 净含量 + 刻度全对 | 同左 | 包装造型不同 |
| 中文信息图 | 段落级 | 四区块 + `1900 M` / `100% 手采` / `72 H` / `210 ℃` 全对 | 同左 | 换行与脚注排布不同 |
| 建筑立面图 | 标注级 | 尺寸线 / 标高 / 标题栏 / 指北针全对 | 同左 | MOSS 线条更重，Qwen 更浅 |
| 电影故事板 | 标签级 | 2×3 + 镜号说明条全对 | 同左 | 分镜内容不同 |
| 四格漫画 | 对话级 | 2×2 + 气泡全对 | 同左 | 画风差异明显 |

**十类全过，无一格失手。** 最难的是「标注级」的立面图（尺寸线、标高、标题栏小字），
两个模型都拿下了。

## 这说明什么

1. **「版式是模型先验」不是 MOSS 独有。** 现代 T2I 普遍有「这是一张卡牌 / 一张信息图」的
   结构先验，第一句「整张…完整展示 / 四边与画面边缘平行」就能把它带进排版模式。
2. **「文字必须逐字注入」同样通用。** 两个模型拿到的是同一份逐块写死的文字，结果都对；
   提示词结构是可迁移的资产，不是某个模型的补丁。
3. **真正的差距在画风。** 同一段提示词，MOSS 出厚涂装饰感，Qwen 出平涂干净感。
   12 部短篇用的是 MOSS 的厚涂口径；换模型等于换画风，要重出。
4. **速度差 2.4 倍。** MOSS 30 步 40–60 秒，Qwen 8 步 18–21 秒。
   批量试版式时用 Qwen 更快，定稿要厚涂质感再回 MOSS。

## 边界

- **单种子单次生成**，不是稳定性结论。要判稳定性需 ≥3 种子复核。
- 文字正确性在整图与放大两种尺度下看过；**交付前仍应逐字核对**，
  小字号块（立面图标注、信息图脚注）是最容易出错的地方。
- 只比两个模型；其余七个家族的结论来自 2026-10-31 的四语文字评测，不是本次重跑。
