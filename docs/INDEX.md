## 十二、索引维护规则

1. **新增编号轨**：新建 `NN_<主题>/README.md` 并在本文件第四节补一节；同轨后续文档在该节内追加行。
2. **新增共享结论**：进 `06_文档与结论/`，并在本文件第五节登记；重复内容不得再复制一份到各轨。
3. **取代 / 归档**：被取代的文档移入 `99_归档/`（本仓既有归档目录，文件名带 `-已去重-<日期>` 或 `旧` 前缀标记来源），`状态` 改 `废弃`；**不删除**。
4. **核对日期**：整仓复核时统一刷新。
