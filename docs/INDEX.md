## 六、索引维护规则

1. **新增编号轨**：新建 `NN_<主题>/README.md`，逐篇清单写在该轨 README，并在本文件第三节补一行；同轨后续文档不再在本页加行，只更新该行的「轨内 tracked 文档数」与核对日期。
2. **新增共享结论**：进 `06_文档与结论/`，在该轨 README 登记后回本文件第三节更新 `06` 行的文档数与核对日期；重复内容不得再复制一份到各轨。
3. **取代 / 归档**：被取代的文档移入 `99_归档/`（本仓既有归档目录，文件名带 `-已去重-<日期>` 或 `旧` 前缀标记来源），`状态` 改 `废弃`；**不删除**。
4. **核对日期**：整仓复核时统一刷新。
