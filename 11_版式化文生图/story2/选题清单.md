## 一、治愈日常（4 个）

### 1. 猫与台风夜 ★ 已制作（厚涂电影感 · 8 页）

- **状态**：2026-11-01 完成，产物在 `pages/`，阅读器 `reader.html`。
- **一句话**：台风夜收留的猫，每晚都回到便利店门口——它在替一个老人等。
- **起承转合**：台风夜捡猫 → 抱进便利店装箱 → 第二天猫不见、只剩一撮毛 → 第三天它又回来、毛全干了 → 他跟猫走三条街 → 发现老人每晚放一碟牛奶 → 老人月底要搬走，猫不肯跟她回去 → 搬家日猫跟他回家 → 他在门口放猫窝和一只小碟子。
- **结局**：她走后猫每晚还在门口坐一会儿，他就在那儿放了一只碟子。
- **视觉资产**：暴雨夜街景、便利店暖白灯、湿透的三花猫、旧木公寓走廊、白瓷碟。

### 2. 便利店的第七年

- **一句话**：夜班店员七年没换班，一个女孩每晚 2:14 来买同一款饭团。
- **起承转合**：他数着她的时间 → 她从不说话 → 他试着搭话失败 → 他递了辞职信 → 最后一晚他问了为什么 → 她答「只有这个点，收银台后面的灯是亮的」 → 他撕了辞职信 → 第二天他把灯换成了更亮的一支。
- **结局**：他留下，灯变亮，她照常 2:14 来。
- **视觉资产**：荧光灯下的便利店、关东煮蒸汽、饭团货架、挂钟指针、玻璃门的夜。

### 3. 阳台上的番茄

- **一句话**：独居老人种了一季番茄，全被隔壁小孩摘了。
- **起承转合**：他每天浇水 → 果子一个个少 → 他守在阳台抓人 → 抓到隔壁小孩 → 他要发火 → 跟到小孩家，看见番茄摆在遗像前 → 他把剩下的一篮全留下了 → 第二年春天他种了两排。
- **结局**：两排番茄，一排自己吃，一排不摘。
- **视觉资产**：阳台铁栏、塑料花盆、红番茄、晾衣杆、昏暗的室内遗像与香。

### 4. 最后一碗

- **一句话**：拉面店关门前最后一天，三个客人各点一碗，谁也不说话。
- **起承转合**：老板贴出关店告示 → 最后一天只来三人 → 三人各坐一角 → 老板认出其中一人是当年常客 → 三人吃完同时放下碗 → 老板问「还要加面吗」 → 三人一起摇头 → 门关上后，老板在账本最后一页写下三个名字。
- **结局**：三碗面，一本账，店关了但名字留下了。
- **视觉资产**：蒸汽、木吧台、三只空碗、暖帘、账本与钢笔。

## 二、怪谈奇幻（3 个）

### 5. 纸灯放流

- **一句话**：把名字写在纸灯上放流，河会实现一个愿望，代价是忘掉一个人。
- **起承转合**：夏日祭的河边 → 摊主说明规则 → 他犹豫 → 他写下自己的名字 → 灯漂远 → 第二天他忘了母亲的脸 → 他翻遍相册只认得背景 → 第二年他又来放灯 → 这次他写的是母亲的名字。
- **结局**：他把自己忘掉的部分，还给了她。
- **视觉资产**：夜河、成百上千的纸灯、浴衣、摊贩灯笼、翻开的相册。

### 6. 雨女的伞

- **一句话**：她撑伞出门就下雨，所以她从不出门。
- **起承转合**：她搬到隔壁 → 他注意到她只在雨天收快递 → 他试着约她，她拒绝 → 他每天「恰好」带两把伞 → 她说出原因 → 他不信，拉她出门 → 果然下雨，两人淋透 → 第二天晴天，她把伞收进柜子，走出门。
- **结局**：晴天，空伞架，她第一次走进阳光。
- **视觉资产**：玄关的伞架、窗外的雨、两把并排的伞、湿透的鞋、晴天的光。

### 7. 座敷童子的房子

- **一句话**：老屋要拆，屋里的座敷童子得跟着搬。
- **起承转合**：老屋空置多年 → 他回来处理拆迁 → 夜里听见小孩跑动 → 他在壁橱里发现小小的脚印 → 拆迁日推土机来了 → 他在空地站了很久 → 他搬进新公寓 → 在角落留了一个小房间，摆一盏灯。
- **结局**：房子没了，房间还在。
- **视觉资产**：老屋走廊、纸门、壁橱、推土机与空地、新公寓的角落。

## 三、青春 / 科幻（4 个）

### 8. 放学后的天文台

- **一句话**：天文社只剩一个人，他在废弃圆顶里收到一段来自三十年后的信号。
- **起承转合**：社团只剩他 → 他每晚去圆顶 → 收到一段杂音 → 解析出是他自己的声音 → 信号说「把望远镜留给下一个来的人」 → 他试过反驳，信号不再回 → 毕业前他把钥匙交给一个新生 → 三十年后他在同一个圆顶里听见当年的自己。
- **结局**：信号是他自己发的，闭环成立。
- **视觉资产**：圆顶、望远镜、示波器、打印纸带、星空。

### 9. 转学生的第七天

- **一句话**：转学生每周一出现、周日消失，全班都记得他，只有主角记得「上周也有一个」。
- **起承转合**：转学生来 → 一切正常 → 周五他开始交代后事般的话 → 周日他消失 → 全班当没这个人 → 只有主角记得 → 第二个转学生来了，长得一样 → 第七天主角替他留了下来。
- **结局**：这次消失的是主角，轮到他被忘记。
- **视觉资产**：教室、空座位、值日表、黑板上的名字、走廊的光。

### 10. 第七次重启

- **一句话**：每天醒来都是同一天，他试了六次都没能救下那个人。
- **起承转合**：第一次事故 → 他惊醒在同一天 → 第二次尝试拦截 → 失败 → 第三到第六次，越来越偏执 → 第七次他决定不救 → 他陪她走完这一天：买面包、喂猫、看落日 → 傍晚事故照常发生 → 第八天，日历翻页了。
- **结局**：他要的不是救她，是好好告别。
- **视觉资产**：重复的闹钟、同一条街、面包店、猫、落日、翻页的日历。

### 11. 复制品的告别

- **一句话**：他被复制了一份，复制品只有七天寿命，负责替他上课。
- **起承转合**：复制品出现 → 两人分工 → 复制品比他更受欢迎 → 第五天复制品开始衰弱 → 第六天复制品说「我想去一次海边」 → 本体翘课带他去 → 第七天复制品在海边消失 → 本体回到学校，坐在复制品的座位上。
- **结局**：他活成了复制品的样子。
- **视觉资产**：两个一模一样的人、教室、电车、海、沙滩上的鞋。
