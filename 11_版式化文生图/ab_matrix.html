怎么读这张表：
  • 版式骨架两个模型都成立；差别集中在文字与质感。
  • MOSS 出厚涂装饰感，Qwen 出平涂干净感；Qwen 快约 2.4 倍。
  • 难度递增大致是 包装 < 塔罗 < 四格 < 海报 < 封面 < 界面 < 故事板 < 信息图 < 档案卡 < 立面图。 「标注级」的立面图（尺寸线、标高、标题栏小字）是全场最难的一格。
  • 为什么只有两个模型：其余家族在 2026-10-31 的四语文字评测里已经暴露出文字能力不足 （FLUX.1-dev 把中文写成韩文；FLUX.2-klein 大面积伪汉字；Krea2 菜单多处错字）， 不再纳入版式对照。判定依据见 06_文档与结论/版式化是否MOSS专属-跨模型对照.md。
