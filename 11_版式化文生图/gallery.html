01

可复刻的七个要素

核心结论：版式是模型的先验，文字是必须显式注入的内容。 同 seed 同参数，1751 字结构化提示词能复刻出逐字正确的卡牌；换成 9 字短提示， 卡牌结构仍然完整，但说明栏文字退化成伪汉字、卡号变成乱码。 由此得到七条可复用规则，详见 docs/版式化提示词七要素.md。

  1. 01

    先声明「这是一件完整的平面物」

    开头第一句不是描述画面，而是锁定对象：整张…完整展示 / 四边与画面边缘平行 / 居中排列 / 四周留少量背景。这一句决定模型进入「排版模式」还是「插画模式」。

  2. 02

    版式骨架用方位词顺序推进

    顶部 → 中央 → 底部，左侧 → 右侧，逐区块描述、不跳序。模型按 token 顺序建版面，乱序会把后提到的区块挤到错位。

  3. 03

    文字块单独成段 +「写出：」+ 空行 + 原文

    文字渲染的触发格式。写出：\n\n青眼白龙\n\n四个字横向排列… —— 换行即分段，原文独占一行，模型才把它当「要画的字」而不是「要理解的描述」。

  4. 04

    文字四件套：颜色 + 字号 + 字体 + 对齐

    每个文字块都给全：黑色 / 大号 / 楷书风格 / 位置偏左。缺任何一项，模型会自己选。

  5. 05

    数量与数值必须写死

    8 枚星、9 格、ATK/3000、89631143、¥3,842.60、1900 M。模糊表述会被四舍五入。

  6. 06

    结尾一段枚举色板做全局收束

    配色限定为米白、深棕、淡赭与一点橙红 比零散提色更能压住一致性。

  7. 07

    否定约束写在相关段落同句内

    「不使用任何彩色」「绝非真人照片」「无阴影无材质」——有效，但堆在末尾会衰减。

05

复用方式

驱动把官方模板的子图摊平成 9 个节点直接提交 /prompt， 不经前端、不改模板 JSON，参数就是参数，没有隐式状态。 

# 0. 必须用 ComfyUI 自带 python，且 ComfyUI 已在 127.0.0.1:8188
# 1. 契约自检：三件套是否在 /object_info 下拉表里（避免静默无图）
python run.py lay --probe

# 2. 列类型 / 跑全部 / 跑指定类型
python run.py lay --list
python run.py lay
python run.py lay tarot dossier

# 3. 自定义：写 recipe.json 交给驱动
python run.py layrun recipe.json

# recipe.json 字段
{ "name": "my_card", "prompt": "...", "width": 1024, "height": 1536,
  "steps": 30, "cfg": 4.0, "sampler": "euler", "scheduler": "simple", "seed": 0 }

模型名口径：模型放在 models/*/MOSS-Image/ 子目录时，组合框合法值是 MOSS-Image\文件名。写裸名会被判 value_not_in_list， 节点输出被忽略、下游剪枝，最终 status=success 但 outputs={}—— 静默无图，最难查。所以第一步永远是 --probe。
