## B 站 · 专栏 ｜ 方法 · 长文（知乎可复用）

**标题**（36 / 50 字）

```
版式是模型的先验，文字必须逐字注入：MOSS-Image 版式化文生图实测
```

**正文**（1578 / 100000 字）

### 一、问题是什么

让文生图模型画「一张完整的游戏王式怪兽卡」「一页九格漫画」「一个手机 App 首页」，
难点不在画得好看，而在**版式和文字同时可控**。

我把这类任务叫「版式化文生图」：一张图 = 一个完整的信息载体，而不是一幅插画。

### 二、口径

| 项 | 值 |
|---|---|
| 模型 | MOSS-Image SFT（int8） |
| 文本编码器 | qwen3.5_9b（int8_convrot） |
| VAE | flux2-vae |
| 硬件 | RTX 5070 Ti Laptop 12G |
| 采样 | euler / 30 步 / CFG 4 / scheduler simple |
| 分辨率 | 宽高均为 16 的倍数，总像素 1M–2M |
| 负向词 | nsfw, worst quality, bad anatomy, watermark, jpeg artifact |
| 耗时 | 1024×1536 约 42 秒；800×1200 约 30 秒 |

单种子单次生成，未修图。

### 三、核心结论：版式是模型的先验

同一 seed、同样参数，把 1751 字的结构化提示词换成 9 个字「青眼白龙，游戏王卡牌」：

| 项 | 结构化提示词 | 9 字短提示 |
|---|---|---|
| 卡牌结构 | 完整 | **仍然完整** |
| 名称栏文字 | 正确 | 正确（提示词里给了） |
| 说明栏正文 | 与原文一致 | **像汉字的笔画组合** |
| 卡号 | 89631143 | ISI A00/1602/VP00/6028 |
| 主体配色 | 银白 + 钢蓝 | 被自行染成绿色 |

模型内置「这是一张卡牌」的版式先验，所以骨架白送；但它不知道你要写什么字。
**提示词的长度，八成花在逐字规定文字上，不是描述画面。**

### 四、七个可复用的写法

1. **先声明「这是一件完整的平面物」**——「整张…完整展示 / 四边与画面边缘平行 / 居中排列 / 四周留少量背景」。这一句决定模型进入排版模式还是插画模式。
2. **版式骨架用方位词顺序推进**——顶部 → 中央 → 底部，左侧 → 右侧，不跳序。
3. **每个文字块单独成段**——`写出：` + 空行 + 原文独占一行 + 排版说明。换行即分段，这是最硬的一条。
4. **文字四件套**——颜色 + 相对字号 + 字体族 + 对齐，缺一项模型就自己选。
5. **数量与数值写死**——8 枚星、9 格、ATK/3000、89631143、¥3,842.60。
6. **结尾一段枚举色板做全局收束**——「配色限定为米白、深棕、淡赭与一点橙红」。
7. **否定约束写在相关段落同句内**——「不使用任何彩色」「无阴影无材质」。

### 五、参数不是关键变量

同一提示词换采样口径，版式与文字都成立：euler / 30 步 / CFG 4 锐度略高，er_sde / 25 步 / CFG 2.5 说明栏文字更连贯、快约 8%。
**稳定性来自提示词结构，不来自采样参数。**

### 六、10 类版式骨架

- **A 单画布排版**：塔罗牌、人物档案卡、杂志封面、电影海报、手机 App 界面、产品包装、中文信息图、建筑立面图
- **B 叙事序列**：电影故事板（2×3 格 + 镜号说明条）、四格漫画（2×2 格 + 气泡）

骨架复用：保留怪兽卡全部版式，只换主体、属性、配色与数值，一次生成即全部落位。

### 七、边界

| 边界 | 现象 |
|---|---|
| 文字密度 | 单图 8–12 个文字块可控，超过后小字号块笔画粘连 |
| 跨格/跨页一致性 | 同页多格脸型漂移；跨页靠逐页复用角色设定卡维持 |
| 规则几何 | 环形进度弧、条形码被画成近似形 |
| 画面元素计数 | 文字里的数字可控，画面元素只是概率性服从 |

### 八、复现

工具、10 类完整提示词、8 页短篇漫画实例都在 ComfyUI-Experiment-Toolbox 仓库第 11 轨（`11_版式化文生图/`）。
驱动把官方模板的子图摊平成 9 个节点直接提交 `/prompt`，参数就是参数，没有隐式状态。
提交前先跑 `--probe` 校验三件套在 `/object_info` 下拉表里——模型名不带子目录前缀时会静默无图。
