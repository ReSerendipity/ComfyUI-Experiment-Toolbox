# 类型库手册

10 类版式骨架，按两条主线分。每类给出：版式骨架 / 文字密度 / 推荐分辨率 / 主要风险点。
提示词正文见 `layout_types.py`（权威来源，本手册只是速查）。

## 两条主线

| 主线 | 定义 | 判据 |
|---|---|---|
| **A 单画布多区块排版** | 一张图 = 一个完整信息载体，内部按区块分区 | 有「标题栏 / 说明栏 / 边角小件」这类**版面构件** |
| **B 多画布叙事序列** | 一张图 = N 个镜头或画格，画格之间有时间顺序 | 有「第 N 格 / SHOT NN」这类**序列标记** |

文字密度四档：**标题级**（≤5 个文字块）→ **标签级**（6–12 个短块）→
**对话级**（气泡台词，每格一句）→ **段落级**（整段正文）。

## A 主线

### A1 塔罗牌 `tarot`

- 骨架：外框（双线 + 四角饰）→ 顶部罗马数字 → 主画面 → 底部牌名（中 / 英 + 编号）
- 密度：标签级 ｜ 分辨率：768×1344
- 风险：罗马数字易写成普通数字；角饰数量不固定
- 适合：单主体 + 强象征，靠符号而非文字撑信息量

### A2 人物档案卡 `dossier`

- 骨架：机密标题带 → 左立绘 / 右信息面板（姓名 · 能力条 · 技能列表 · 信息块）→ 印章
- 密度：标签级 ｜ 分辨率：1024×1536
- 风险：能力条形图长度必须与数值一起写（`体能 8` + `条形长度与数字成正比`），否则不成比例
- 适合：角色设定集、游戏内角色卡

### A3 杂志封面 `magazine`

- 骨架：刊名横贯顶部 → 期号 → 主视觉 → 左侧导读 N 条 → 价格角标 → 底部条码
- 密度：标题级 ｜ 分辨率：1024×1536
- 风险：文字压在亮部会糊，必须写「文字全部为纯白色」并让主视觉暗部偏冷
- 适合：需要「一眼可信」的出版物仿真

### A4 电影海报 `poster`

- 骨架：主视觉占上 2/3 → 标语 → 主标题（中 / 英）→ 底部 credit block → 上映信息
- 密度：标题级 ｜ 分辨率：1024×1536
- 风险：credit block 四行小字容易糊成纹理，要写「以极小的白色字母分四行居中排布，行距紧凑」
- 适合：宣发物料、概念海报

### A5 手机 App 界面 `app_ui`

- 骨架：状态栏 → 问候区 → 主数据卡（环形图）→ 三分类卡 → 列表 → 底部 tab
- 密度：标签级 ｜ 分辨率：768×1664（9:19.5）
- 风险：**环形进度弧会被画成分段**（已知弱点）；图标容易被画成写实插画，要写「线性图标」
- 适合：产品原型、UI 概念图

### A6 产品包装 `packaging`

- 骨架：封口条 → 圆形插画 → 品牌名 → 品名 + 风味 → 刻度条 + 净含量 → 产地行
- 密度：段落级 ｜ 分辨率：1024×1024
- 风险：几乎无；本类型是全库里最稳的一类，可直接投产参考
- 适合：快消品包装概念、电商主图

### A7 中文信息图 `infographic`

- 骨架：标题带 → N 个等高区块（图标 + 阶段名 + 说明 + 关键数字）→ 来源脚注
- 密度：段落级 ｜ 分辨率：1024×1536
- 风险：区块等高靠「四个等高的横向区块」+「区块之间以细虚线分隔」两句共同压住
- 适合：科普、流程说明、数据叙事

### A8 建筑立面图 `elevation`

- 骨架：图框 → 正立面（轴线对称）→ 尺寸线 / 标高符号 → 标题栏 → 指北针
- 密度：标注级 ｜ 分辨率：1280×864
- 风险：**开窗数量不服从**（写 3 扇会出 5 扇）；纯线稿要求写「不使用任何彩色」
- 适合：工程图仿真、蓝图风格

## B 主线

### B1 电影故事板 `storyboard`

- 骨架：标题栏 → 2×3 画格 + 每格下方说明条（`SHOT 01 / WIDE / CRANE DOWN`）
- 密度：标签级 ｜ 分辨率：1280×720
- 风险：说明条要写「与画格等宽」，否则会缩成小标签
- 适合：分镜预览、影视提案

### B2 四格漫画 `yonkoma`

- 骨架：2×2 等大画格 → 起承转合 → 每格一枚台词气泡
- 密度：对话级 ｜ 分辨率：1024×1024
- 风险：气泡要指定形状（圆 / 锯齿 / 爆炸），否则四格都用同一种
- 适合：短篇搞笑、日常向

## 怎么加新类型

1. 在 `layout_types.py` 的 `TYPES` 里加一项：`label / family / density / skeleton / size / prompt`
2. `size` 两个数都取 16 的倍数，乘积落在 1M–2M
3. `prompt` 按 `docs/版式化提示词七要素.md` 的骨架模板写，**文字块一律独占一行**
4. `python gen_types.py <新key>` 出一张，对照 `skeleton` 逐项验收
5. 验收通过再补进本手册

## 类型 × 变体：五个正交维度

固定的是骨架，变体只换槽位：

| 维度 | 例子 |
|---|---|
| 主体替换 | 卡牌 → 不同怪兽 / 塔罗 → 不同大阿尔卡纳 / 海报 → 不同片种 |
| 属性槽位 | 星级 8→4、ATK 3000→1800、能力条数值、期号与价格 |
| 文字密度 | 标题级 → 标签级 → 段落级（密度越高越要逐块给字号与对齐） |
| 画幅比例 | 2:3 / 16:9 / 1:1 / 9:19.5 |
| 材质风格 | 做旧纸质 / 蓝图线稿 / 赛璐璐平涂 / 哑光牛皮纸 |
