# 版式化提示词七要素

> 2026-10-29 定稿 ｜ 依据：ModelScope AIGC 专区两张版式化作品（游戏王怪兽卡、九格漫画页）的
> 逐段拆解 + 本地 MOSS-Image 复刻验证 + 10 类扩展实跑
>
> 一句话：**版式是模型的先验，文字是必须显式注入的内容。**

## 0. 先看一个反例

同一 seed、同一参数（euler / 30 步 / CFG 4 / 1024×1536），把 1751 字的结构化提示词
换成 9 个字「青眼白龙，游戏王卡牌」，结果：

| 项 | 结构化提示词 | 9 字短提示 |
|---|---|---|
| 卡牌整体结构 | 完整 | **仍然完整**（名称栏 / 属性徽章 / 等级星 / 方框插画 / 说明框 / ATK-DEF 行） |
| 名称栏文字 | `青眼白龙` | `青眼白龙`（猜对，因为提示词里有） |
| 说明栏正文 | 与原文逐字一致 | **伪汉字**，笔画是汉字形状但不成词 |
| 卡号 | `89631143` | `ISI A00/1602/VP00/6028` |
| 主体配色 | 银白 + 钢蓝 | 被模型自己染成绿色 |

结论：模型内置了「这是一张卡牌」的**版式先验**，所以骨架白送；但它不知道你要写什么字，
所以**文字必须逐字给出**。原作提示词之所以长，八成篇幅都在规定文字。

由此得到七条规则。

---

## 要素 1 · 先声明「这是一件完整的平面物」

第一句不写画面内容，先锁定拍摄对象：

```
竖版2:3画幅。整张卡牌正面完整展示，四边与画面边缘平行，居中排列，
周围留少量深蓝灰色背景。
```

四个关键词各管一件事：

| 词 | 作用 |
|---|---|
| `整张…完整展示` | 禁止裁切，强制全身入画 |
| `四边与画面边缘平行` | 压住透视，禁止斜拍 / 俯拍 |
| `居中排列` | 给出居中锚点 |
| `周围留少量X背景` | 给出留白比例与背景色 |

这一句决定模型进入「**排版模式**」还是「**插画模式**」。写「一条银白色的龙站在尖塔上」
得到的是插画；加上这一句才得到卡牌。

## 要素 2 · 版式骨架用方位词顺序推进

顶部 → 中央 → 底部，左侧 → 右侧，逐区块描述、**不跳序**。

模型是按 token 顺序建版面的。先写底部再写顶部，它会把后写的内容挤到错位。
两个样本的段落顺序都严格是「外框 → 顶栏 → 中部主图 → 底栏 → 边角小件」。

区块之间用一句话过渡，说明相对关系，而不是重复坐标：

```
名称栏下方、中央插画框上方，靠右排列一行等级星。
中央插画下方设置宽大的浅米白色说明框。
```

## 要素 3 · 每个文字块单独成段 +「写出：」+ 空行 + 原文

这是文字渲染的**触发格式**，也是最关键的一条：

```
左侧以黑色大号楷书风格汉字写出：

青眼白龙

四个字横向排列，笔画有清楚的粗细变化，字距舒展，位置偏左。
```

三个动作缺一不可：

1. `写出：` —— 显式声明「下面这几个字是要画的」
2. **空行 + 原文独占一行** —— 换行即分段，模型把它当独立文本对象编码
3. 原文后面再补一句排版说明 —— 把「字」和「字怎么排」分开

如果写成一行 `左侧写出「青眼白龙」四个字`，文字照样能出，但字号与位置会飘。
独占一行时命中率明显更高。

**多行文本**同理，每行一段：

```
说明框左上方以黑色楷体文字写出第一行，字号略大：

【龙族/通常】

下一行以稍小的黑色楷体准确写出：

以高攻击力著称的传说之龙。任何对手都能粉碎，其破坏力不可估量。
```

## 要素 4 · 文字四件套：颜色 + 字号 + 字体 + 对齐

每个文字块都给全，缺一项模型就自己选：

```
以白色粗体无衬线中文写出          ← 颜色 + 字重 + 字体族 + 语言
字号略大 / 极大 / 较小            ← 相对字号（不要写 px）
位置偏左 / 居中 / 与右侧对齐      ← 对齐
```

字号用**相对词**（极大 / 大号 / 中号 / 小号 / 极小）比绝对值稳：模型没有像素概念，
但它理解「比上一块大」。

## 要素 5 · 数量与数值必须写死

```
数量固定为8枚
含 9 格分镜版面
ATK/3000  DEF/2500
89631143
¥ 3,842.60
1900 M
```

写「几枚星」「一些数字」会被模型四舍五入成它习惯的样式。
带数量的阵列还要补一句「大小一致，间距均匀，排列在同一条水平线上」，
否则它会画成大小渐变。

**注意**：数量约束对**文字里的数字**有效，对**画面元素**只是概率性服从。
实测 8 枚星能稳定成立；建筑立面「三扇窗」会变成五扇——这类要靠构图描述加强，
或者接受偏差。

## 要素 6 · 结尾一段统一收束材质 / 配色 / 光影

把色板收敛成**枚举**：

```
整体为克制的精品咖啡包装设计风格，配色限定为米白、深棕、淡赭与一点橙红，
排版以居中对齐为主，留白充足，纸质哑光。
```

「配色限定为 A、B、C 与一点 D」比在每段里零散提颜色更能压住整体一致性。
这一句要放在**最后**，因为它是对全图的归一化约束。

## 要素 7 · 否定约束要显式写出来

```
不使用任何彩色
绝非真人照片
无阴影无材质
不要出现水印或作者签名
```

模型对否定句的响应是有效的，但要写在**相关段落的同一句里**。
单独堆在末尾效果会衰减。

---

## 附：参数是不是关键？

不是。同一提示词换采样口径：

| 口径 | 结果 | 耗时 |
|---|---|---|
| euler / 30 步 / CFG 4（原作标注） | 版式文字全对，锐度略高 | 42.2s |
| er_sde / 25 步 / CFG 2.5（官方模板默认） | 版式文字全对，说明栏文字更连贯 | 39.1s |

**稳定性来自提示词结构，不来自采样参数。** 参数只影响锐度与耗时。
所以本轨的调优顺序永远是：先改提示词结构，再动参数。

## 附：一个可复用的骨架模板

```
<画幅与平面物定位>：竖版2:3画幅。整张<物>完整展示，四边与画面边缘平行，
居中排列，四周留少量<背景色>背景。

<底材与整体结构>：<材质>，<色系>。外缘<边框描述>。

<区块 1 顶部>：<位置>设置<元件>，<颜色/字号/字体/对齐>写出：

<文字原文>

<区块 1 的排版说明>。

<区块 2 中央>：……

<区块 3 底部>：……

<边角小件>：……

<统一收束>：整体为<风格>，配色限定为<枚举>，<排版原则>，<质感>。
```
