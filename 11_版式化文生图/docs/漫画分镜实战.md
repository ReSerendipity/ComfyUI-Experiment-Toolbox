# 漫画分镜实战：用本轨做一篇连贯短篇

> 实例：《末班车开往海见》8 页，数据在 `story/story_data.py`，产物在 `story/pages/`
>
> 目标不是"画得好看"，是**读得通**：剧情有起承转合、台词逐格落位、角色跨页能认出是同一个人。

## 0. 先认清这件事的难点

MOSS-Image 是 **T2I，没有参考图输入**。所以"角色一致性"不是靠锁 seed 或参考图，
只能靠**每一页逐字重复同一段角色设定卡**。这决定了三件事：

1. 角色设定必须是**可复述的视觉事实**（发色、发型、制服形制、配饰、身形），不是性格形容
2. 每页提示词里这段文字**一个字都不能改**，否则模型会当成不同的人
3. 接受面部细节漂移——这是能力边界，不是调参能解决的

## 1. 写故事圣经（先于任何出图）

三样东西必须先定，且写进文件：

| 项 | 例子 |
|---|---|
| 一句话故事 | 废线前的末班车上，他遇见一个在废站等了三十年的少女 |
| 起承转合表 | 相遇 → 日常 → 疑点 → 试探 → 真相 → 抉择 → 送别 → 结局 |
| 结局 | 她道谢后消失，留下发带；多年后他成了拍这条线的摄影师 |

**结局必须在写第一页提示词之前就定死。** 否则做到第 6 页会发现收不回来，
而重做前面几页的成本是线性的。

## 2. 定角色卡与画风卡（逐页复用）

```python
STYLE = (
    "统一画风：日式彩色漫画，清晰黑色描线，赛璐璐平涂上色，柔和光影，杂志彩页质感，"
    "绝非真人照片。"
)
CAST = (
    "角色设定（每一格都保持一致）：\n"
    "悠人，十七岁日本男高中生，黑色短发略乱，眉眼安静，穿深藏蓝色立领学生制服，"
    "白衬衫领口露出一线，身形清瘦。\n"
    "千夏，十六七岁日本少女，齐肩黑色直发，浅蓝色旧式夏季水手服，白色三本线领，"
    "深红色发带系在左侧，白色帆布鞋，肤色偏白，神情安静。"
)
```

两条经验：

- **画风卡要带否定句**（`绝非真人照片`）。不带的话，日式漫画会被画成厚涂写实。
- **角色卡要带"左/右"这类方位锚点**（`深红色发带系在左侧`）。只写"戴发带"，
  下一页发带会换边，读者会以为是两个人。

### 2.1 角色卡要按页取子集

角色卡是**全篇共享**的，但每页只该出现本页的人物。把三个人一起塞进每页提示词，
模型会把没登场的角色也画进来——实测 P1 脚本只有少年和猫，成品里老人站在了便利店门口。

做法：角色卡拆成 dict，按页传子集，并补一句收口。

```python
CAST = {"透": "阿透，十四岁……", "佐": "佐和子，七十多岁……", "猫": "三花猫，……"}

def page(body, tone, style_block, cast=("透", "猫")):
    people = "\n".join(CAST[k] for k in cast)
    return (body.strip() + "\n\n" + style_block + "\n\n"
            + "本页出场角色（只画这几个，不要出现其他人物）：\n" + people + "\n\n"
            + "整页各格的人物造型、服装细节与画风保持一致，" + tone + "。")
```

空镜那一格再补一句「这一格不出现人物」，否则模型会在远景里塞个人进去凑数。

### 2.2 黑白网点：否定句不够，要给替代方案

想换黑白画风时，只写「完全不使用任何彩色」是**无效的**——实测成品仍有蓝色卫衣、
橘色斑块、绿色眼睛。模型需要知道"那用什么代替"。

有效写法是逐项交代网点替代方案，并在负向词里点名颜色：

```
统一画风：日式黑白网点漫画，印刷在纸上的单色漫画。全图只使用黑、白与不同密度的灰色网点，
没有任何彩色。人物与场景的明暗一律用网点密度表现：亮部留白，中间调用稀疏网点，
暗部用密集网点与纯黑实心。三花猫的橘色与黑色斑块用深浅不同的灰色网点区分，
眼睛用留白与细线表现。整体如同复印在纸上的漫画原稿。
```

负向词追加：`color, colorful, chromatic, saturated colors, blue, orange, red, green`。

改完立刻真变黑白。**这条对任何"去掉某种属性"的需求都成立**：不只说不要什么，
还要说"用什么顶上"。

## 3. 分页：一页 = 一个节拍

8 页的节拍分配（每页 3–4 格）：

| 页 | 节拍 | 格数 | 关键道具 |
|---|---|---|---|
| 1 | 相遇 | 3 | 车灯 / 空车厢 |
| 2 | 日常 + 埋疑点 | 4 | 站牌「海见」 |
| 3 | 查证 | 3 | 旧剪报 |
| 4 | 试探 | 3 | 穿过脚踝的灯光 |
| 5 | 真相 | 3 | 站牌上的日期 |
| 6 | 抉择 | 3 | 废线公告 |
| 7 | 送别 | 4 | 车窗倒影 / 跨海大桥 |
| 8 | 结局 | 3 | 发带 / 旧站牌 |

**每页只推进一步。** 一页塞两个节拍，读者会跟不上，模型也会把两件事画进同一格。

### 3.1 一页最多几格：先崩的不是格数

单页格数上限的实测（`panel_test.py`，同一幕对白戏、同 seed，只改格数）见
`06_文档与结论/漫画格数上限实测.md`。结论不是「超过 N 格就崩」，而是**按层判**：

| 层 | 从第几格开始出问题 | 实测表现 |
|---|---|---|
| 台词文字 | 4 格内没失效 | 逐字正确 |
| **气泡归属** | **6 格起进入抽签** | 6 / 8 / 12 格都抽中错：女主台词被安到男主脸上 |
| 文字保真 / 格数控制 | 8 格起 | 8→10、9→12、12→13；9 格还编出了剧本里没有的台词 |

**这几层各自独立抽签，不是同一条下降曲线。** 9 格那页归属全对，但冒出了编造台词
（「蓬亮着，一个人摊位」）、站牌写成「站街草」；12 格反过来是归属错、文字没编。
所以 5 格以上要逐格核两件事：**气泡指向谁、气泡里是不是原文**。

**4 格是「对白 + 气泡归属 + 格数控制」三样全对的最后一档。** 加分辨率救不回来
（1024×1536 同样漂）——瓶颈是模型对版面的注意力分配，不是像素。

所以做短篇时，页内格数控制在 3–4 格（本仓 12 部都这么排）；要更密的节奏就拆成两页，
不要硬压一页。

### 3.2 每格先决定类型：说 / 白 / 静

每格落笔前先定它属于哪一型，否则整页会退化成「给图配字幕」：

| 型 | 形态 | 装什么 |
|---|---|---|
| **说** | 圆形气泡 + 写明谁说的 + 尾部指向 | 人物台词 |
| **白** | 矩形框 | 只补画面看不到的信息（时间、地点、前情），**不得复述画面** |
| **静** | 无字 | 反应、停顿、环境 |

两条硬规矩：

- **旁白不能复述画面。** 写「车站没有人」「灯亮着」这类看图就懂的句子，就是在配字幕。
- **说话人必须逐格写死。** 只写「气泡尾部指向说话的人」等于留空；写成
  「气泡尾部明确指向千夏」才生效。写死之后 4 格全对，6 格起仍会错，只能逐格核。


## 4. 写单页提示词

固定五段式（与 `docs/版式化提示词七要素.md` 同源）：

```
① 画幅与平面物定位：竖版 2:3 画幅，一整页日式漫画，四边与画面边缘平行，居中排列，四周留少量白色页边。
② 画格布局：版面自上而下分为三个横向画格：第1格较扁，第2格最高，第3格中等。
             格与格之间留出均匀的白色间隙，每个画格外围有一圈细黑边框。
③ 画风卡 + 角色卡（逐页逐字复用）
④ 逐格描述：第N格，景别：内容。气泡/旁白框的位置与台词。
⑤ 收束：整页各格的人物造型、服装细节与画风保持一致，色调以…为主。
```

第 ④ 段里，台词的写法与版式化完全一致——**单独成段，原文独占一行**：

```
画格右下角有一枚白色圆形气泡，气泡尾部指向千夏，内部以黑色中文写出：

这条线……还会开很久吗？
```

三个细节决定成败：

- **景别写死**（大远景 / 中景 / 近景 / 特写）。不写景别，三格会全是中景，读起来像三张并排的插画。
- **气泡位置 + 指向**（`气泡尾部指向千夏`）。不写指向，气泡会飘在画格角落，读者不知道谁在说话。
- **旁白框与气泡要区分**（矩形 vs 圆形）。混用会让内心独白和台词分不清。

## 5. 生成与落盘

```powershell
python 11_版式化文生图/story/gen_story.py --plan      # 先看分镜与提示词长度，0 提交
python 11_版式化文生图/story/gen_story.py 1           # 先做一页验收
python 11_版式化文生图/story/gen_story.py             # 全 8 页
python 11_版式化文生图/story/gen_story.py --index     # 只重建 story.json，不出图
```

脚本经 `/view` 取回产物并压成 jpg，**不依赖本机 ComfyUI 的 output 目录**，
所以换机器只要有 ComfyUI 在 8188 就能跑。

阅读器：`python 11_版式化文生图/story/build_reader.py` → `story/reader.html`，
一页一屏、方向键翻页。页表内联进 HTML（`file://` 下 `fetch` 读 JSON 会被 CORS 拦）。

`--index` 的意义：只重跑单页时，索引仍会全量重建，不会把其它页从 `story.json` 里丢掉。
（这个坑第一次就踩了：先跑 P1，再跑 P2–P8，索引里只剩 P2–P8。）

## 6. 验收清单

逐页对照，不通过就换 seed 重跑该页（不要重跑全部）：

- [ ] 画格数与布局和脚本一致
- [ ] 每格景别不重复堆叠
- [ ] 台词逐字正确，**气泡指向明确且指向对的人**（多人同格时重点核这一条）
- [ ] 旁白框与气泡形状区分
- [ ] **旁白没有复述画面**（没有「车站没有人」这类配字幕句）
- [ ] 画面里的文字载体（纸条 / 招牌 / 信 / 标签）都逐字给了原文
- [ ] 角色发型 / 制服 / 配饰在页内各格一致
- [ ] 跨页能认出是同一角色（允许面部细节漂移）
- [ ] 最后一页能独立成立为结局

## 7. 本篇的偏差记录（如实记账）

| 页 | 偏差 | 处置 |
|---|---|---|
| 1 | 第 2 格两人并排而非对坐 | 接受，构图更好 |
| 5 | 第 1 格多画了悠人跟下车（脚本只写千夏） | 接受，反而补上了"他跟着下车"的动作 |
| 7 | 第 2 格画成鞋子而非车窗倒影 | 接受，情绪等价 |
| 2/5/6 | 站牌与公告出现日文汉字「海見」「潮見線」 | 接受，日式设定下更自然 |

**结论：分镜脚本要留出"模型自由发挥"的余量。** 逐字锁死每一格的构图，反而会
让模型在别处崩掉；锁死**景别、台词、关键道具**，构图留给模型，成品率更高。
